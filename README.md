Overview

MediCare Plus is a modern Hospital Management System designed to digitalize hospital workflows and improve communication between patients, doctors, and administrators. The system provides a centralized platform for appointment booking, patient record management, and hospital administration.

It is built with a scalable architecture using a mobile-first frontend and a secure backend API system.

🎯 Objectives
Digitize hospital operations
Improve communication between users
Centralize patient medical records
Automate appointment scheduling
Enhance healthcare efficiency
✨ Features
👤 Patient Module
Secure registration and login
Book and manage appointments
View prescriptions and medical history
Receive notifications
👨‍⚕️ Doctor Module
Manage appointments
Access patient records
Update prescriptions and reports
Manage availability
🛠 Admin Module
Manage doctors and patients
Approve/reject appointments
Monitor system activity
Full system control dashboard
🧰 Tech Stack
Layer	Technology
Frontend	React Native
Backend	Python Flask
Database	MySQL
API	RESTful APIs
⚙️ Installation & Setup
🔹 Backend Setup (Flask)
git clone <your-repo-link>
cd backend

pip install -r requirements.txt

python app.py
🔹 Frontend Setup (React Native)
cd frontend

npm install

npx react-native run-android
🚀 How to Run Project
Start MySQL server
Run Flask backend
Start React Native app
Connect app with backend API
Login as Patient / Doctor / Admin
🔐 Security Features
JWT / session-based authentication
Role-based access control (RBAC)
Secure REST APIs
Encrypted data handling
